# 湾 / DSH Bay v0.1.2 更新说明

这次更新让湾跟随 DSH 切换中英文，也简化了从空工作台开始第一次对话的步骤。

## 一个安装包，两种界面语言

在 DSH 的 **设置 → 通用设置 → 语言** 中选择中文或 English。湾的首页、侧栏、内页设置、项目和对话引导、Agent 组装、工具统计、分享和导入界面随之切换。不需要另装英文版。

语言设置只影响界面：项目与对话名称、文件路径、草稿及第三方扩展内容保持原样。仓库首页也改为中文，并在顶部保留 [English README](../README.en.md)。

## 从空区域开始对话

1. 区域还没有项目时，只推荐不依赖对话的内页，也可以直接点「设置项目」。
2. 项目还没有对话时，空区域优先显示「新建对话」。
3. 打开「新建对话」后，当前项目已选中；选择 Agent 模式即可开始，不必再手动找项目。

## 分享与浏览器交互

- 模板包和完整包统一使用 `.dshbay.zip`。导出可选保存目录，导入和导出均显示进度；导出保留文件名中的中文，同名文件不会被覆盖。
- 模板包用于复用工作台结构，不含项目文件和对话历史；完整包可迁移项目文件和支持恢复的会话。导入改进了项目绑定和会话登记，恢复的会话可在对应项目的列表中找到。
- 修复从浏览器打开工作台时无法回答提问或确认审批的问题。
- 当前分享页不接受旧版布局包或对话归档包。完整包可能包含项目文件、附件和对话历史，分享前请确认内容与接收权限。详见[工作台包格式](WORKBENCH-PACKAGES.md)。

## 安装与验证

- **产品版本**：`v0.1.2`。
- **Core 试用包**：`dsh-bay@0.1.2-0.1.1.1`。按[仓库首页](../README.md#开始试用)的步骤构建，再通过 DSH 原生插件管理器安装 `.tgz`。
- **DSH 兼容范围**：`>=0.2.2-rc.3 <0.2.3`；本次使用 `0.2.2-rc.3` 验证。
- **验证范围**：自动化测试、类型检查和构建通过。在隔离的 DSH 环境中安装试用包，实测中英文往返切换、内置内页与侧栏、创建工作台和项目，以及新建对话自动选中项目。独立桌面窗口和完整包导入、导出的端到端流程未在本轮实测。
