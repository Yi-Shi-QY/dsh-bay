# 18.0 内页菜单分类

文档复核：2026-11-11，当前功能基线 `ab2a7d8`。规则已实施；文末保留 2026-11-10 的专题验证，最新整版结果见 [验证记录](VALIDATION.md)。

区域添加／切换内页与浮动工作区添加内页共用 `WorkbenchEditorPicker`。内页数量增加后，菜单采用可折叠的分类文件夹。

## 操作规则

- 对话、新建对话、Agent 轨迹和其他官方内页统一归入“官方内置”，始终排在最前。
- 扩展未手动分类时使用扩展声明的默认分类；没有声明时归入“扩展”。
- 桌面端“工作台设置 → 内页与扩展 → 菜单分类文件夹”支持新建、重命名和删除分类。扩展卡片提供每个内页的分类选择。
- 分类名称为 1–32 个字符，不允许重名及使用保留名称“官方内置”“扩展”。文件夹按创建顺序排列。
- 文件夹标题显示图标、展开箭头和当前可见内页数量。没有可用内页的分类不出现在添加菜单中。
- 收起状态在当前窗口内保留，关闭并重新打开菜单仍有效。搜索时临时展开匹配分类，清空搜索后恢复原状态。支持按名称、内页标识及分类名称搜索。
- 上下方向键移动焦点；分类标题上的左右方向键展开／收起；搜索结果只有一个可用内页时可按 Enter 打开。
- 删除分类仅移除菜单分组和对应分配关系，内页回到默认分类。扩展、磁盘文件和已打开的内页不受影响。

## 保存与范围

`WorkbenchSettingsV4.editorMenu` 保存 `{ folders: [{ id, name }], assignments: { [editorId]: folderId } }`。

分类是本机全局菜单偏好，与现有 `globalHiddenEditorIds` 作用范围一致，保存在宿主登记的偏好中，不写入每个工作台定义。稳定文件夹 ID 使重命名不影响内页归属；未加载或暂不可用扩展的分类关系继续保留。

所有分类操作通过目录适配器的 `updateEditorMenu(command)` 提交，使用现有 Settings 版本冲突检查。名称、引用和官方内页约束在共用模型中验证。

浏览器主控读取同一分类投影；当前分类管理入口仅在桌面端设置中提供。局域网访客不获得本机全局分类偏好。该偏好尚不作为完整工作台包的可迁移数据。

## 实现位置

- `foundation/editor-menu-preferences.ts`：分类模型、校验、编辑和展示分组解析。
- `foundation/WorkbenchEditorPicker.tsx`：共享分类菜单、搜索和键盘操作。
- `foundation/WorkbenchEditorFolders.tsx`：分类管理和扩展分类选择。
- `foundation/frame-settings-adapter.ts`、`persistence.ts`、`host-layout-settings.ts`：提交、读取和持久化结构。
- `foundation/WorkbenchFrame.tsx`、`WorkbenchFloatingWorkspace.tsx`：区域和浮动菜单传入相同偏好。
- `host-workbench-access.ts`、`foundation/settings-context.ts`：浏览器主控投影。
