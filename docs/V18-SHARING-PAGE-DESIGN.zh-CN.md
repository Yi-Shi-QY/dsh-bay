# 18.0 分享与迁移页设计与实施

2026-11-10，基于 `main` 的 `1f59ddf` 及未提交的总览卡片调整。

## 页面目标

将原来同时堆叠的完整包、布局分发、导出和导入表单，整理成按操作与包类型选择的工作流。沿用 DSH Bay 的主题变量、原生图标、圆角与按钮规范；用户首先知道正在处理哪一种包，再看到对应的配置、预览和结果。

## 页面结构

- 标题及说明：分享与迁移。
- 操作切换：导出工作台、导入工作台、导入记录。
- 包类型：完整工作台包、布局与扩展。宿主提供完整包服务时默认完整包；显式的“打开分发向导”入口直接进入布局与扩展。
- 导出采用双栏：左侧来源与配置，右侧已保存布局、区域/内页数量及内容范围。按钮保持正常宽度。
- 导入采用双栏：左侧文件选择、上传进度与目标目录，右侧恢复步骤。界面明确两类包支持的文件格式。
- 完整包作业统一显示在下方：实际阶段、文件条目、已处理字节、更新时间，以及下载、取消或继续操作。没有总进度数据时使用不定进度条，不编造完成百分比；上传百分比来自实际已接收字节。
- 窄窗口下配置与预览上下排列，操作和包类型均可完整访问。深色、浅色共用主题变量。

## 组件与行为边界

`WorkbenchSharingPage` 管理操作、包类型与来源工作台。`WorkbenchCompletePackagePanel` 继续复用现有完整包客户端、上传续传、目录许可与持久作业；`WorkbenchDistributionPage` 保留原分发预览、导入确认、扩展安装及事务恢复。`WorkbenchSharingSummary` 只渲染已保存布局，不触发额外文件或模型读取。

`WorkbenchSettingsOpenOptionsV1.shareType` 是可选页面导航参数，取值为 `complete` 或 `distribution`，不写入工作台定义或完整包。

切换包类型采用隐藏保留组件，正在进行的上传不会因切换展示而被销毁。两类导出共用来源选择，避免看着一个工作台却导出另一个。无工作台时禁用导出，保留完整包导入入口；桌面已交给浏览器控制的工作台继续遵守原写入限制。

布局与扩展导入仍先预览、确认，再开始恢复。完整包导入后仍保持待继续；本次改动没有执行模型任务或重放历史。
