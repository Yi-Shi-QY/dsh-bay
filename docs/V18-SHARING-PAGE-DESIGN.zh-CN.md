# 18.0 分享与迁移页设计与实施

更新日期：2026-11-11。创建／完整包导入优化已提交为 `ab2a7d8` 并完成实验包交付；当前制品与验收范围见 [验证记录](VALIDATION.md)。下文保留初版及后续流程的验证时点。

## 页面目标

将原来同时堆叠的完整包、布局分发、导出和导入表单，整理成按操作与包类型选择的工作流。沿用 DSH Bay 的主题变量、原生图标、圆角与按钮规范；用户首先知道正在处理哪一种包，再看到对应的配置、预览和结果。

## 页面结构

- 标题及说明：分享与迁移。
- 操作切换：导出工作台、导入工作台、导入记录。
- 导出与历史提供包类型切换；目录型工作台的导入统一使用完整包 V5。移除“可以选择布局包，但服务随后拒绝”的导入入口。旧格式不自动迁移。
- 导出采用双栏：左侧来源与配置，右侧已保存布局、区域/内页数量及内容范围。按钮保持正常宽度。
- 导入分为选择与检查、内容与位置、恢复工作台、完成四个状态。左侧操作，右侧显示包中真实工作台名称、布局缩略图、区域／项目／文件／会话／记忆／任务数量。默认目录名使用显示名称；选择位置后显示最终目标路径。
- 当前导入进度与恢复报告在主操作区显示；其他作业在导入记录中查看。完成后分别显示数据、环境和任务状态，桌面提供“打开工作台”，浏览器提示在 DSH 打开新工作台，不自动切换当前主控。没有总进度数据时使用不定进度条；上传百分比来自实际已接收字节。
- 窄窗口下配置与预览上下排列，操作和包类型均可完整访问。深色、浅色共用主题变量。

## 组件与行为边界

`WorkbenchSharingPage` 管理操作、包类型与来源工作台，桌面与浏览器共用。`WorkbenchCompletePackagePanel` 负责上传、目录许可、持久作业和恢复状态；`WorkbenchImportFlow` 展示导入步骤与摘要；`WorkbenchCompleteJob` 展示作业及完整恢复报告。`WorkbenchSharingSummary` 复用已保存布局预览，不挂载内页运行时。

`WorkbenchSettingsOpenOptionsV1.shareType` 是可选页面导航参数，取值为 `complete` 或 `distribution`，不写入工作台定义或完整包。

切换操作保留上传状态，两类导出共用来源选择。桌面新导入使用独立作用范围，导入历史汇总所有导入作业；不依赖当前工作台是否由浏览器主控。浏览器导入仍限定当前主控身份。无工作台时禁用导出，保留首次导入入口。

目标目录冲突在消耗目录许可、创建恢复作业前返回，用户可直接改名或重新选择目录，无需重新上传。已经创建但未开始恢复的失败作业，可通过 `reset-import-location` 返回位置设置，旧作业失去执行资格；已写入数据的作业保持原身份和位置继续恢复。丢失开始响应时，客户端先查询目录许可关联的作业，再决定是否提交，避免重复创建。

预检增加 `overview` 内容摘要；布局投影只返回区域、内页标识与标题，不返回内页状态或原生绑定。目录许可增加只读 `displayPath`，作业增加 `name`、`targetDisplayPath`、`canChangeDestination`。显示路径不作为操作许可。导入仍使用 Host 保存的目录许可和持久映射。

## 创建工作台

创建弹窗优先展示名称、父目录与最终路径。自定义文件夹名称、区域布局、工作背景按需展开，布局可以在弹窗内切换而不清空已填内容。沿用原生图标、主题变量、轻边框与紧凑按钮。

目录创建前由 Host `create-preflight` 检查父目录及重名；错误时保留可编辑表单。AI 草稿、目录检查、创建与打开使用独立状态。提交后结果不明确时，保留原请求和表单，继续同一次操作。

创建适配器保留同一请求的原始记录，避免日期与区域身份重新生成导致请求指纹冲突。目录已经登记而 Main 初始化或会话刷新失败时，重试可以继续到 Host，不被同名工作台检查拦截。

所有 UI 检查和预览均不调用模型，AI 辅助按钮仍由用户主动触发。完整包导入不执行历史工具或自动继续任务。
