# 17.4 开发约定

开始日期：2026-11-05。开发版本：0.2.2-alpha.17.4。
基线：已合并的 17.3，提交 9064452；宿主继续使用 DSH 0.2.1-rc.5。
开发分支：feature/alpha17.4-ui。

## 本轮范围

- 以用户逐项提出的 UI 修改为主，沿用 DSH / DeepSeek 的既有设计语言。
- 保留 17.3 的原版交互隔离、浮动工作区、浏览器控制权交接及已完成的修复。
- 每项修改执行与改动范围相符的测试、必要构建及视觉验证。
- 只有用户明确要求“打包”后才生成新的插件安装包；不得为单项 UI 调整自动打包或安装候选包。
- 验证优先使用隔离环境，不修改日常 Profile。

## 当前状态

已建立 17.4 开发分支，统一根包、Core、Creator 模板兼容声明和版本身份元数据。已完成下述对话标记色联动，并在用户明确要求后生成了新的 17.4 私有试用包：`releases/alpha17.4-private/dsh-workbench-core-0.2.2-alpha.17.4.tgz`。

17.3 的 112 个既有 generated/upstream 类型错误仍是正式发布阻断基线。17.3 已交付包及其验证记录保留原版本，不将历史验收结果描述为 17.4 验收。

## 对话标记色与容器边框

- 已绑定区域复用顶栏对话标记的颜色，沿左上边缘显示向右、向下渐淡的 1px 线框；选中区域增强，其他区域减弱，收起区域不额外描边。
- 收起的浮动工作区入口跟随当前选中区域的绑定色；展开窗口跟随当前活动临时内页的来源对话色。没有绑定时保持中性，不借用另一个区域或对话的颜色。
- 区域标签与边框使用同一绑定解析及标记记录，不改变现有对话焦点、自动事件路由、布局存储或包协议。
- 边框不参与布局及指针命中；保留点击、拖动、缩放和关闭交互，支持高对比度及减少动画设置。

### 本次验证

- `pnpm test`：120 个测试文件、746 项测试全部通过。
- `pnpm build` 和 `pnpm check:rc5` 通过。
- 用户明确要求打包后，已重新生成私有试用包，并解压核对包名、版本、`lib/index.js`、`lib/client.js`、`lib/build-inputs.json` 和 Creator 模板。
- `pnpm typecheck` 仍有 112 个既有错误；与 17.3 基线按错误内容归一化比对，无新增、无消除。正式发布门禁仍未通过。
- 隔离 Web Profile 中通过 Edge 检查深浅主题、1440×1000 和 820×650 视口、360px 浮窗、选区与标签切换、未绑定状态、高对比度、减少动画及标签关闭；无页面异常或失败网络请求。
- 视觉验证通过响应替换加载当前 17.4 开发客户端，配合隔离环境已安装的 17.3 Host。该结果不代表 17.4 安装包的桌面安装验收；日常 Profile 未改动。

## 绑定对话菜单这一版

- 按照原有操作习惯收回为单层选择器，宽度收窄到总宽度 340px，保留顶部搜索、当前绑定、最近对话和原有标记编辑入口。
- 最近对话仍按更新时间展示；输入搜索词时仍可检索全部候选，不增加额外的模式切换控件。
- 项目文件夹标题改为可展开/收起的分组按钮，收起时只隐藏该项目下的候选，不改变当前绑定。
- 搜索、Enter、Escape、点击外部关闭和绑定命令保持原有语义；没有改动布局命令、跨项目打开或绑定代际。
- 组件测试和构建通过；隔离视觉验证确认菜单总宽度为 340px，覆盖收窄后的菜单交互。项目分组的展开/收起由 DOM 状态和按钮语义实现；当前隔离 Profile 只有一个可用项目分组，未产生第二个候选分组，因此没有伪造视觉验收结果。未打包。

## 浮动工作区层级与顶栏这一版

- 浮动窗口的顶栏、来源栏和内容区使用明确的局部层级；渐变描边仍作为装饰层显示，但不会盖住窗口菜单、缩放热区或可操作按钮。
- 窗口菜单提高到描边之上，并保留在浮动窗口内部，不改变工作台全局 Portal 菜单的层级；菜单打开后仍可点击放入区域、切换临时内页、选择来源对话和重置位置。
- 顶栏窗口操作归入独立操作组，保持“添加内页”跟在最后一个标签后面；窗口较窄时隐藏最大化按钮，避免与标签和最小化按钮重叠。
- 临时标签关闭、浮动工作区菜单、最大化/还原、最小化、关闭提示均补齐 `title` 和可访问名称；原有键盘和关闭保护逻辑不变。
- `floating-workspace-controls.client.spec.tsx`、`workbench-empty-area.client.spec.tsx`：13 项测试通过；全量 `pnpm test` 为 120 个文件、745 项测试通过；`pnpm build` 通过；本轮仍未打包或安装候选包。

## 浮动工作区视觉回调与图标这一版

- 浮动窗口恢复此前的中性表面、边框、阴影和菜单视觉，不再使用上一版新增的品牌渐变、顶栏导线、彩色发光和按钮重绘。
- 只替换 `FloatingWorkspaceIcon`：参考用户提供的鲸鱼、拱形和波浪构图，使用内嵌 SVG 绘制海湾图标；窗口控制、来源项目和来源对话图标回到上一版形态。
- 新图标只改变浮动工作区入口和空状态中的图形，不新增运行时状态、布局字段、导出字段或交互路径；无障碍名称、键盘操作、关闭保护和拖拽固定语义保持不变。
- 浮动工作区回到中性视觉后的源码已重新构建并打包；本次产物只用于隔离环境私测，未进行桌面安装或 Browser Companion 实测。
