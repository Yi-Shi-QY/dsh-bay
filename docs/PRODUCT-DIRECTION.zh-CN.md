# 产品方向

## v0.1 要解决的问题

DSH 插件和 Skill 的创作过程对新手不够连续：开发工具、可复用资产、实际使用、验证和分享往往彼此分散。湾希望把这些步骤放进一个可持续改进的工作台中。

## 产品判断

湾同时服务两类创作者。熟悉 DSH 的人需要明确接口、来源证据和细粒度控制；没有开发基础的人需要可运行的起点、循序渐进的修改路径和清楚的验收反馈。两者最终都需要把个人经验沉淀为可重复使用的工作台。

## v0.1 范围

- 创建和组织多区域工作台。
- 使用 Creator Skill 和模板开发扩展。
- 将工作项、Agent 和 Assignment 纳入工作流。
- 检查依赖、版本兼容和上游来源。
- 导出可迁移的布局或完整工作台包。
- 在受控局域网环境中尝试多人协作。

## 暂不承诺

v0.1 不承诺任意 DSH 版本兼容、无网络安装所有扩展、跨 DSH 代际无损迁移、公开模板市场、远程公网协作或所有模型提供方的稳定性。相关能力需要真实用户场景和部署环境验证。

## 公测学习目标

公测首先需要收集真实任务，而不是只收集功能偏好。每个模板都应记录：适用人群、前置条件、解决的任务、使用步骤、验收标准、已知限制，以及从使用反馈迭代的历史。
