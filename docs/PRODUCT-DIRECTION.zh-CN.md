# DSH Bay 产品方向

更新日期：2026-11-11。当前候选为 `0.2.2-alpha.18.2` / DSH `0.2.2-rc.1`；当前源码工作树尚未提交。

本文保留产品方向摘要。完整定位、目标用户、成功标准、功能矩阵与长期路线统一维护在[项目手册](PROJECT-HANDBOOK.zh-CN.md)，实际操作见[使用教程](USER-GUIDE.zh-CN.md)。后续路线是建议开发顺序，不承诺版本号或发布日期。

湾域将项目、对话、任务和工具内页放进一个可继续工作的空间。插件开发仍是主要使用场景，工作台目录、Bay Agent 和完整包让长期工作与交接有明确的归属。

## 当前闭环

1. 创建工作台，选择父目录，预览最终路径；布局和背景按需配置。
2. 创建区域并关联根内项目，项目持有背景、记忆及会话/任务关系，区域负责呈现。
3. 在项目概览打开历史对话或新建对话；使用原生内页和扩展处理工作。
4. 通过 Bay Agent 组织任务，从实时 Agent 模式目录选择 Worker；继续任务优先续用原会话。
5. 用完整工作台包 V6 迁移文件、历史、附件、任务关系与可迁移扩展；接收方配置环境后主动继续。导入先准备文件和布局，再确认扩展、重启并恢复会话数据。

关闭区域即移除该展示空间。新区域关联原项目会找到同一份背景、记忆和历史入口，不恢复旧区域或自动打开全部标签。

## 产品界面

- 总览以工作台列表与选中详情并排展示，底部保留导入/创建入口。
- 项目概览集中管理项目背景、记忆、历史对话和任务，减少容器菜单负担。
- 创建弹窗先呈现名称、存放位置和最终路径；导入采用检查、位置、恢复、完成四阶段。
- 浮动工作区是辅助工具与 Main 的显示位置；收回 Bay Agent 标签只改变该标签显示，不删除会话。
- 浏览器接管沿用同一工作台数据和扩展许可，桌面管理页保留进度、收回与目录选择入口。

界面沿用 DSH Bay 主题变量、原生图标、轻边框和紧凑布局，深浅主题与窄屏一起验证。

## 交付与后续工作

当前唯一运行时包为 `dsh-bay`，插件安装和模式执行使用 DSH 原生服务。完整工作台包是离线迁移；在线局域网分享是 Host 承载的协作，两者不是同一能力。

当前优先稳定 18.x，补充[未完成的实机验证](VALIDATION.md)。下一轮源码结构优化需要独立讨论服务边界和依赖，再决定性能优化切入点。本次文档整理不新增源码目录重构、IM、云端同步或公开市场承诺。
