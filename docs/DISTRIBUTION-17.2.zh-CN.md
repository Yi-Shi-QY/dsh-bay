# 17.2 工作台分发与私有内页迁移

工作版本为 0.2.2-alpha.17.2，完整分发仅接受 DSH 0.2.2-rc.1 和精确兼容的扩展。17.1 的 Home、三步创建和全关闭承接继续保留。

工作台管理、导入、导出与导入记录统一位于“工作台总览”，桌面工作台设置仅保留内页与扩展、交互偏好。总览卡片支持搜索和状态筛选，通过“管理”编辑资料、置顶、检查区域内页、归档、恢复或确认永久删除。

最后一个工作台也可归档或删除；删除当前打开项会在保存检查后同时关闭视图与移除记录。目录清空后显示首次引导，重启仍保持空总览；归档保留布局，永久删除不删除 DSH 对话或终止任务。保存冲突和浏览器占用仍会阻止操作。Browser Companion 继续保留固定工作台的受限设置与布局分享。

## 三种模式

| 模式 | 文件内容 | 接收方需要 |
| --- | --- | --- |
| 布局分享 | 全部保留标签、顺序、选择、几何、元数据及可迁移配置 | 自行安装扩展；缺失项保留占位和待恢复数据 |
| 在线引用 | 布局、配置、签名、精确依赖锁和 HTTPS Registry | 本地配置来源凭据；下载内容须与锁定摘要完全一致 |
| 离线嵌入 | 布局、配置、签名、全部已核对的扩展运行安装包 | 兼容 DSH/Core；不需要发送者私库或源码 |

完整包检查失败会阻止生成，不会自动降级。用户可以主动改选布局分享。旧 V3、V1/V2 和 Suite 包仅经明确的布局兼容转换导入，不通过兼容入口自动安装扩展。

## 房主导出

在首页卡片选择导出，或进入 Settings 的工作台分享页，选择模式并检查。首次完整导出通过 Host 凭据服务生成并回读 Ed25519 私钥；无法持久保存就停止。接收者可用发布者指纹向房主核对。

持久安装的 Bundle 优先使用经过验证的原始 tarball；开发目录必须显式准备制品。仅收集 runtimeFiles 精确列出的运行入口、必要资源、Bundle 配置和许可证。不会递归打包工程或运行构建命令。所有保留标签及插件依赖都参与检查。

每个内页必须有 exportState/importState；无状态页面也必须有明确的空投影。处理器只传递受大小、声明和敏感字段检查的 JSON。原始运行状态不会作为迁移兜底。离线完整不包含 Profile、DSH Runtime、源码、会话、凭据、本机路径、私有文件、模型或外部服务。Session 和工作目录由接收者重新绑定。

## 接收方导入

导入页先检查文件、签名、权限和冲突，再集中确认来源、安装/复用清单、Host 执行影响和工作台授权。确认绑定当前 Profile、事务、包摘要及权限，不形成永久发布者信任。

安装使用 DSH 公开原生 package operations 和 Profile 写锁，强制禁用生命周期脚本、安装钩子及隐式 peer 下载。离线安装与失败修复均强制离线。在线模式先下载并核对精确版本及完整性，再进入相同安装阶段；当前只支持同源 HTTPS Registry 和接收方 Profile 的 token 配置。

新插件先禁用安装，核对实际运行文件后持久化启用选择，显示“需要重启”。重启 DSH 后从导入记录继续；实际注册和身份验证通过，才调用配置恢复并使用 Settings CAS 提交新的工作台。完成后由用户点击“打开导入的工作台”，不会自动替换当前工作台或创建 Session。

完全相同的插件可以复用。版本或内容不同、Bundle 入口 ID 冲突、来源身份不能证明、不可修改的插件均阻断自动替换，需用户在 DSH 原生管理器处理。

## 失败与取消

事务、同意、安装归属和待恢复配置保存在 Host。重启可继续；取消只删除本事务新增且归属仍可证明的插件，不删除复用插件。插件开关恢复前核对当前选择摘要；其他窗口改动会转为需要恢复，避免覆盖其选择。已运行插件需停用并重启后再清理。删除成功但日志写入前中断可对账重试。

Settings 冲突不会覆盖另一个窗口的新设置；工作台只在最后提交。布局分享缺失扩展时，配置保存在 Host 待恢复记录，之后精确匹配包名、版本、运行摘要、editor ID、scope 和授权再恢复。占位页已被用户改动时停止自动恢复。

无法确认回退完成时显示恢复状态及原因，不能当作成功。Host 代码已经造成的文件、网络或外部服务副作用不能承诺回滚。

## 安全与范围

签名证明该发布者签署了这些内容，不证明扩展作者身份或代码安全。工作台授权不是 Host 插件沙箱。自包含检查使用语法解析和精确文件清单，保守拒绝动态模块路径等不可验证形式；它不是对任意 JavaScript 行为的安全证明。

敏感分发、签名、制品和安装入口由 Host 身份校验保护；LAN 网关同时阻断 HTTP 与等价 RPC/mux 路径。Browser Companion 保持试用指定工作台，不获得分发安装权限。Dynamic Cordis、Agent/MCP/Skill 的完整迁移不在本期。

## 验证与交付

自动测试、构建、真实双 Profile 安装分别记入 VALIDATION.md 和交付目录 candidate.json。测试用隔离 Profile，不修改日常 Profile。网络验收使用不可达 Registry、独立空 store、Node 非本机连接/DNS 拦截及浏览器非本机请求拦截；这不是物理断网或操作系统全进程网络隔离证明。

正式 pack:core 继续受 typecheck 门禁约束。既有 RC1 Sidebar/Workspace 声明问题未修复前，只交付明确标注 experimental 的私有试用包。必须逐一核对归档版本、Host/Client 字节摘要、Creator 模板、构建输入和最终 SHA-256，不能以构建成功代替新包生成。
