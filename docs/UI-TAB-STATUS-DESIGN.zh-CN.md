## 2. 产品规则：统一含义，各自报告真实状态

状态标记帮助用户回答三个问题：哪里需要我处理，哪里还在进行，哪里已经完成一次工作。

| 标记 | 统一含义 | 示例文案 |
| --- | --- | --- |
| 红色实心点 | 当前工作在等待用户处理 | 等待审批、等待答复、等待确认计划 |
| 黄色实心点 | 有一项明确的操作正在进行 | 正在生成回复、命令执行中、正在加载文件、专注计时中 |
| 绿色实心点 | 一项有明确终点的工作已确认成功完成 | 本轮已完成、命令执行成功、本次专注完成 |
| 红色叹号 | 操作失败，或者内页当前不可用 | 本轮失败、连接失败、扩展不可用 |
| 灰色空心点 | 尚缺必要条件，或者状态无法确认 | 待绑定对话、正在同步状态、状态未知 |
| 灰色暂停标记 | 对象确实已暂停或被手动停止 | 计时已暂停、本轮已停止、预览已暂停 |
| 不显示标记 | 非对话内页处于普通、健康、无活动状态 | 正常查看文件、终端空闲、网页已打开、指南可阅读 |

对话尚未开始或空闲时可保留灰色中性点，延续已讨论的对话方案。非对话内页正常无活动时隐藏；灰色标记只用于明确的待绑定、暂停、停止或未知状态。

“已打开”“已连接”“已挂载”“正在查看”都不能直接映射为绿色。未读、未保存、已选中也不复用红黄绿的含义。

### 2.1 状态属于哪个对象

- 对话：绑定的具体会话及最新一轮。
- 轨迹：它明确展示的那段会话，悬浮文案标明“关联对话”。
- 终端：具体终端连接；获得命令级事件后，再显示具体命令的执行结果。
- 浏览器：当前内页发起的页面导航或预览状态。
- 文件、计划、变更、计划任务：当前展示的具体资源或任务。
- 扩展插件：当前实例，或者插件明确声明的共享业务对象。

同一容器里的内页不能因为共享会话绑定而全部变色。例如，对话正在生成时，同区域中的文件树、浏览器和番茄钟不自动变黄。

## 3. 各类内页的建议表现

| 内页类型 | 平时 | 需要用户处理 | 操作进行中 | 成功后 | 关键边界 |
| --- | --- | --- | --- | --- | --- |
| 对话 / Bay Agent 主控对话 | 灰色中性点 | 红点，区分审批、计划确认、答复 | 黄点 | 绿点保留到下一轮开始 | 主控对话的绿色只表示主控本轮结束，不表示所有 Worker 或工作项完成 |
| 子 Agent 对话 | 跟随实际展示的子会话 | 红点 | 黄点 | 本轮正常完成后绿点 | 使用子会话自己的状态，不沿用父会话颜色 |
| Agent 轨迹 | 关联对话空闲时隐藏 | 关联对话待处理时红点 | 关联对话运行时黄点 | 关联对话本轮正常完成后绿点 | 提示写“关联对话 · …”；轨迹列表有内容不代表仍在执行 |
| 新建对话 | 正常等待输入时隐藏 | 通常无此状态 | 确实正在创建、准备会话时黄点 | 创建成功后进入实际对话的状态规则 | 新建成功本身不显示“本轮完成” |
| 工作区文件 / 文件预览 | 正常浏览时隐藏 | 仅明确存在待用户处理的操作时红点 | 用户触发且可观测的加载、导入等操作可黄点 | 普通加载完成后隐藏 | 文件有改动不自动变黄；未保存不自动变红 |
| 终端 | 连接正常、Shell 空闲时隐藏 | 只有结构化事件明确要求确认时红点 | 建连时可黄点；命令级事件接入后可显示执行中 | 只有命令明确成功才绿点 | Shell 存活不等于命令运行；输出停止不等于命令成功 |
| 浏览器 | 网页正常打开时隐藏 | 仅工作台掌握的明确用户确认请求可红点 | 可观测的导航加载可黄点 | 导航结束后隐藏 | iframe 的 load 事件不能证明网站内容正常，不显示成功绿点 |
| 计划 | 阅读计划时隐藏 | 当前计划存在真实确认请求时红点 | 当前计划的生成、修改操作可黄点 | 有明确的本次生成或修改成功事件才绿点 | 计划文档存在、计划里有未勾选步骤，不自动构成待审批或执行中 |
| 变更审查 | 阅读差异时隐藏 | 真实存在待批准或待决定的审查请求时红点 | 有明确的生成差异、验证、应用操作时黄点 | 本次具体操作确认成功才绿点 | 看到 diff 不代表待审批；操作完成不等于整项开发已验收 |
| 计划任务 | 等待下一次触发时隐藏 | 当前执行等待用户处理时红点 | 本次执行中黄点 | 本次成功后绿点 | 提示标明“上次执行成功”；到下一次启动转黄，启用计划本身不变黄 |
| 功能指南 / 纯展示页 | 隐藏 | 通常无此状态 | 仅明显、可观测的首次加载可黄点 | 隐藏 | 不为了保持外观一致而持续显示灰点或绿点 |
| 第三方扩展 | 正常无活动时隐藏 | 插件报告的真实待处理请求可红点 | 插件报告的实际活动可黄点 | 有明确成功事件才绿点 | 未接入状态报告时，只显示工作台能确定的可用性问题 |

表中没有可靠数据支持的状态暂不启用。先显示能证明的事实，不从页面名称、文本、输出频率或 DOM 外观推测。

### 3.1 番茄钟示例

以截图中的番茄钟为例，建议如下；这是扩展接入后的目标行为，尚未核实该插件是否提供相应接口。

| 计时状态 | 标签表现 | 悬浮文字 |
| --- | --- | --- |
| 初次打开，尚未开始 | 隐藏 | 标签仍显示“番茄钟” |
| 正在专注 | 黄点 | 番茄钟 · 专注计时中 |
| 正在短休息 / 长休息 | 黄点 | 番茄钟 · 短休息计时中 / 长休息计时中 |
| 手动暂停 | 灰色暂停标记 | 番茄钟 · 计时已暂停 |
| 本次计时自然结束，等待下一步 | 绿点 | 番茄钟 · 本次专注完成 / 本次休息完成 |
| 自动开始下一个计时阶段 | 黄点 | 提示更新为新阶段，上一阶段的完成记录留在内页 |
| 手动重置、跳过后回到待开始 | 隐藏 | 不把重置或跳过记为成功完成 |
| 插件故障 | 红色叹号 | 番茄钟 · 计时异常 |

计时自然结束通常是完成事件，不单独制造“待审批”红点。只有插件的业务确实要求用户确认才能继续时，才报告待处理。

本轮标签无需显示秒数或进度百分比；详细进度保留在内页，避免标签频繁变化。

## 4. 状态冲突与生命周期

### 4.1 每个标签只显示一个主状态

工作台先确定状态归属和数据是否有效，再在当前有效事实中决定主标记。

1. 内页不可用、绑定失效等直接阻止使用的问题优先显示红色叹号。仍然有效的业务状态可在悬浮说明中补充，但不继续展示旧成功状态。
2. 存在有效的待审批、待答复、待确认请求时显示红点，即使底层同时报告运行中。
3. 当前操作已明确失败时显示红色叹号。
4. 当前操作运行中显示黄点。
5. 当前操作已暂停、手动停止时显示灰色暂停标记。
6. 最新一次操作确认成功且没有更新的工作时显示绿点。
7. 必要条件未满足或状态待同步时显示灰色空心点；健康空闲按内页类型显示灰色中性点或隐藏。

如果待处理与失败属于同一次操作且同时有效，优先显示可处理的红点，悬浮文字说明具体问题。属于旧轮次、旧绑定、旧导航的事件不参与排序。

“等待执行”与“等待下一次定时触发”分开：已提交、正在队列中的具体操作可以用黄点并写“排队中”；仅配置了未来计划则隐藏。

### 4.2 绿色的持续与清除

- 绿色只在获得明确成功事实后出现，不因 `running` 从 true 变成 false 就自动出现。
- 查看、聚焦、切换标签不清除绿色；绿色不承载“未读完成”含义。
- 下一轮工作真正开始时转黄；手动重置该操作、切换所绑定对象后，清除原对象结果。
- 用户只是输入草稿、修改尚未提交的参数时，不提前判定新一轮已开始。
- 定时任务在下一次执行前，可保留上次成功绿点，但提示必须写明“上次执行成功”。
- 刷新或重启后，仅在权威数据能确认最新操作结果时恢复绿色；否则显示待同步或中性状态，不从旧截图、旧本地颜色恢复成功。
- 普通文件读取、网页导航完成恢复隐藏；它们没有需要保留的任务成功标记。

### 4.3 收起与暂停分开

收起容器只改变显示位置。会话或后台任务还在执行时，状态仍应是黄点；等待审批仍应是红点。

只有任务本身确实暂停，或者一个没有后台任务的预览确实被暂停时，才显示灰色暂停标记。内页的 React 组件被卸载，不足以证明会话、Shell 或计时任务已经停止。

对话标签在区域收起期间继续观察真实状态；其他随预览暂停的内容在展开后重新订阅。不得把“重新挂载完成”当作业务成功。

### 4.4 多实例与切换对象

- 同一会话同时出现在多个容器或浮窗时，共享同一个会话状态；某个实例无法展示内容时，可用性问题只覆盖该实例的主标记。
- 终端、浏览器、插件按真实对象区分实例，两个浏览器标签不会因为使用同一个编辑器 ID 而串色。
- 更换会话、资源、终端或导航对象后，旧对象迟到的完成事件不能覆盖新对象状态。
- 新一轮开始后，上一轮迟到的成功事件不能把当前黄点变绿。
- 连接断开、来源不再有效时撤下无法确认的红黄绿；有明确失败则红色叹号，仅丢失状态则灰色空心点并说明原因。
- 常驻 WebSocket、后台轮询、自动刷新和 Shell 进程存活不构成持续黄点。

## 5. 标签与操作表现

- 保留现在图标与标题之间的位置，每个标签最多一个状态槽。隐藏时不绘制可见圆点；状态出现时尽量不使标签宽度跳动。
- 首版采用静态实心点，不使用持续闪烁、呼吸或声音提醒。叹号、暂停和空心形状用于区分失败、暂停、未知。
- 悬浮提示格式为“内页名称 · 具体状态”，例如“终端 · 正在连接”“轨迹 · 关联对话等待审批”。
- 提示中说清可采取的动作，例如“切换到对话处理审批”；点击状态点仍执行原标签的切换、展开或菜单动作，不直接批准或重试。
- “全部内页”列表和收起区域预览使用相同状态，并提供文字；搜索可匹配状态文字。
- 标签的读屏描述包含状态，保留原有操作名称；列表直接提供状态文字。不能只通过颜色表达。
- 窄容器优先保留当前标签的关键状态，压缩标题或次要操作；非当前标签被收纳后，可在“全部内页”中找到其状态。
- 收起区域中，继续使用角标位置显示状态。收起预览展示每个内页的文字状态。
- 浮动内页采用同一业务状态规则；现有未读提醒和 Bay Agent 身份标记保留各自含义，不伪装成这套红黄绿状态。
- 普通短暂加载可延迟显示以避免闪烁，初步建议 300 ms；审批、答复请求和明确失败立即显示。具体尺寸、主题色和延迟在视觉验收时微调。

## 6. 当前实现与数据接入条件

### 6.1 设计前核对的基线（87b034d）

| 当前能力 | 已知事实 | 对本方案的影响 |
| --- | --- | --- |
| 标签可用性 | 当前只有 ready、unbound、missing、paused；ready 为灰点 | 需要增加业务状态投影，并调整正常非对话内页的默认显示 |
| 对话运行与待处理 | DSH `SessionStatus` 提供 running、pendingInteraction；工作台侧边栏已识别 approval、plan-review、question | 可复用同一来源，避免每个标签自行轮询 |
| 完成提醒 | `completionUnread` 表示在主视图外观察到停止后尚待确认；它会受查看行为影响 | 不能直接用作“一轮成功完成且持续显示”的事实 |
| 收起暂停 | 当前标签只在 collapsed 策略为 dispose 时传入 pausedTabId | 需要改为实际生命周期与业务状态共同判断，不能直接把收起当暂停 |
| 终端 | 内页已有连接阶段、进程退出、退出码、可写性等信息 | 能支撑连接状态；尚不能仅据此证明 Shell 中某条命令开始或成功 |
| 浏览器 | 当前 iframe 适配器已注明 load 不能证明网站正常渲染 | 首版只表达可观测的导航、错误与未知状态，不声明网页业务成功 |
| 第三方扩展 | 现有声明包含绑定、持久化和生命周期；预览契约是展示投影 | 尚未发现统一的标签业务状态报告接口；不能把预览 badge 直接当权威状态 |

### 6.2 接入思路

工作台负责统一颜色、形状、提示与优先级；业务状态由了解该对象的原生数据源或插件提供。

建议先在 Core 内建立统一状态投影，再逐类接入；本草案不预先冻结公开 API 名称或修改插件契约版本。

每条业务状态至少要能说明：所属实例或共享对象、当前操作身份、状态、简短原因，以及如何判断其仍然有效。工作台还需要识别新旧操作顺序，防止迟到事件覆盖最新状态。

插件提供“正在进行／等待处理／成功／失败”等语义，颜色由工作台决定。工作台自身确认的授权、绑定与可用性问题优先；插件报告的成功不能覆盖“扩展不可用”。

未接入的新旧插件继续可用：正常时隐藏状态点，工作台检测到不可用或待绑定时仍显示对应提示。没有插件状态数据时，不推测它是否正在工作。

对话、轨迹的状态共享订阅；终端、导航、插件按对象订阅。界面不可见不应停止观察真实后台工作，也不应为每个标签新增定时网络请求。

### 6.3 实施前需要核实的信号

1. **第一批已核实：** DSH 的持久记录包含 `turn/start`、`turn/end`、轮次和事件顺序；`turn/end.data.reason.kind` 区分 `completed`、`aborted`、`error`、`blocked`、`max-tokens`、`interrupted`、`forked`。只有 `completed` 可映射为绿色。
2. 轨迹、子 Agent 对话能否稳定取得其实际展示的会话身份。
3. 终端是否有可靠的命令起止与退出结果事件；没有时先只做连接状态，不显示命令成功。
4. 计划、审查、计划任务当前暴露的是文档、会话还是具体任务事实，按实际对象接入。
5. 番茄钟等外部插件是否愿意提供实例级状态，是否存在后台继续计时、自动进入下一阶段等行为。

不能确认的信号写明限制，逐项验收时再决定接入范围。

## 7. 分批实施与验收建议

第一批已实现，其他批次仍待逐项推进。每批单独讨论、实现和验收，不因本文描述了全部类型就一次性改完。为避免同一对话在不同入口呈现不同含义，第一批同时覆盖对话的浮动标签、列表与收起预览。

| 批次 | 建议范围 | 完成标准 |
| --- | --- | --- |
| 1 | 对话标签红黄绿与失败、未知状态（已实现，待验收） | 审批优先、正常完成准确、停止失败不误绿、多容器一致 |
| 2 | 非对话默认隐藏、统一可用性提示、列表与收起展示 | 普通页面安静，异常可发现，窄布局不丢关键信息 |
| 3 | 有可靠信号的官方内页逐个接入 | 每类都核对事实来源，并明确无法判断的状态 |
| 4 | 插件状态报告与番茄钟样例 | 插件主动报告、实例隔离、重置和阶段切换正确、旧插件兼容 |
| 5 | 其余类型的浮动工作区适配及完整视觉回归 | 对话浮窗已随第一批覆盖；其余类型接入后逐项验证 |

### 验收场景

| 场景 | 预期 |
| --- | --- |
| 新对话尚未发送 | 中性灰点，不显示成功 |
| 对话开始生成或调用工具 | 黄点，提示进行中 |
| 运行期间弹出审批 | 立即红点；审批处理后继续执行则回黄 |
| 等待计划确认或答复 | 红点，文案区分原因 |
| 对话本轮正常完成 | 绿点，查看标签后仍保持 |
| 手动停止、执行失败、断线 | 分别显示停止、失败或未知；均不误绿 |
| 已完成对话开始下一轮 | 绿转黄，旧轮次迟到事件不能覆盖 |
| 同一对话在两个容器及浮窗打开 | 业务状态一致 |
| 切换标签绑定后收到旧会话事件 | 不污染新绑定状态 |
| 收起正在运行或待审批的区域 | 仍黄或红，不因收起显示暂停 |
| 普通文件、网页、指南健康空闲 | 隐藏状态标记 |
| 终端 Shell 存活但无命令状态接口 | 不持续黄，不凭终端输出停止显示绿 |
| 命令结果接入后退出码非零 | 红色叹号，不能绿 |
| 网页触发 load 或跨域导航不可观测 | 不宣称任务成功；正常导航回隐藏，未知状态如实提示 |
| 番茄钟开始、暂停、继续、自然结束 | 黄、灰暂停、黄、绿依次正确 |
| 番茄钟重置、跳过、自动进入休息 | 重置或待开始时隐藏；自动开始新阶段时黄，不把跳过算成功 |
| 周期任务等待触发、执行、成功 | 隐藏、黄、绿；保留绿色时注明上次结果 |
| 未接入状态报告的插件 | 正常可用且无活动信息时隐藏；基础错误仍可见 |
| 扩展被停用但仍缓存成功状态 | 不可用覆盖旧成功 |
| 多个同类型插件实例 | 互不串色；明确共享业务对象的实例除外 |
| 页面刷新、恢复工作台 | 从真实状态恢复，无法确认结果时不恢复旧绿点 |
| 全部内页、收起预览、键盘与读屏 | 状态文字可发现，点击行为保持标签原义 |
| 窄容器、浅色与深色主题 | 标记可辨，关键状态不被按钮挤掉，无明显布局抖动 |

## 9. 第一批实施记录（2026-11-08）

### 9.1 已实现范围

- `workbench.conversation` 的普通对话、Bay Agent 主控对话，以及以此编辑器打开的 Worker 对话；不根据“会话作用域”把其他资源编辑器一并变色。
- 红点表示等待原生审批、计划确认或答复；黄点表示运行或已接受的输入等待处理；只有最新一轮的持久结束原因为 `completed` 时显示绿点。
- 手动停止、中断、未结束轮次的分叉显示灰色暂停；失败、受阻、输出上限和消息发送失败显示红色叹号；无法确认的状态显示灰色空心点。空白且尚未开始的对话显示中性灰点。
- 绿点不受未读清除、查看、切换标签影响。新一轮的运行或输入到达时偏好交互这也换成胶囊开关
- 撤下旧绿点，等待本轮真实结果；快速失败即使未观察到运行阶段，也不会沿用旧绿点。
- 区域标签、全部内页、收起预览、浮窗标签和浮窗内页列表使用相同结果。区域收起导致内容卸载时，对话状态仍继续更新。
- 同一会话在多个标签中共享一次原生引用；更换绑定或关闭最后一个标签时清理引用与订阅，不新增轮询，不把状态持久化到布局，不确认或清除未读。
- 全局连接断开时显示待同步；重连后等待原生日志流的新完整基线再恢复可信结果。已归档、缺失或移出绑定项目的会话优先显示不可用提示。
- 对话标记在窄布局保留；状态有悬浮文字、读屏描述，失败与暂停通过形状区分。初版使用静态标记。

Bay Agent 的绿点只证明**主控对话本轮完成**，不证明所有 Worker 或工作项已经完成或通过人工验收。浮窗末尾原有的主控身份标记、未读提醒仍各自独立。

## 10. 第二批：内页标签悬浮信息（2026-11-08）

### 10.1 设计决定

- 所有容器内页标签共享同一套悬浮卡。悬浮不会激活、重新绑定或加载内页；点击、拖拽、键盘切换仍由标签本身处理。
- 对话显示真实对话名称、Agent 模式、项目、状态和区域位置。名称优先使用会话的持久 `title`，没有时使用同步到的显示名称；模式显示已知内置名称或原始自定义模式 ID。模式尚未同步与明确未配置分别显示。
- 文件预览显示所属对话、项目和已解析路径；浏览器只显示已保存且可确认的 HTTP(S) 地址，导航状态不确定时标记为“上次已知地址”；计划只显示标题，不显示正文。
- 轨迹、子 Agent、变更审阅、计划、定时任务等资源根据资源地址解析实际所属会话，不继承父会话的 Agent 模式。资源或会话信息缺失时显示“信息暂不可用”，不猜测。
- “全部内页”和浮动工作区的“全部临时内页”搜索名称、Agent 模式、项目、状态、路径和网址，搜索结果直接激活对应标签。正常空闲时不新增状态提示，悬浮卡只提供定位信息。
- 悬浮卡使用原有 Tooltip 的门户定位、窄屏翻转和键盘焦点支持；Esc 可以收起提示，长路径在有限宽度内换行。
