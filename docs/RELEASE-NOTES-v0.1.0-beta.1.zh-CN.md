- Core 包：`dsh-bay@0.1.0-beta.1`

## 公测注意事项

Beta 期间，工作台布局、扩展 API 和导入导出格式仍可能调整。导入来自不可信来源的插件可能执行代码；安装前应检查发布者、来源、权限和制品。不要把凭据、Session transcript 或私有工作路径放入分享包。

本版本的自动化与人工验证状态见 [v0.1 验证记录](VALIDATION-v0.1.zh-CN.md)。该公开快照只有一个初始 Git 提交，不携带开发过程中的私有提交历史。
