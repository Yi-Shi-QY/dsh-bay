# 浏览器工作台

湾可以通过浏览器参与 DSH Workbench 协作。浏览器页面是受限的参与端，具体可用操作取决于 Host 提供的协作通道、工作台共享状态和当前访问权限。

## 参与边界

- 浏览器协作者可以查看 Host 分享的工作台快照，并提交协议允许的工作台或画布操作。
- 文件系统、插件安装、凭据和任意终端仍由 Host 控制，不会因为浏览器加入而转移给访客。
- Session 和共享草稿受协作协议约束；离开共享不应被理解为获得或保留 Host 的私有数据。
- 房主可以控制共享焦点和连续画布操作；冲突时客户端需要重新同步。

## 部署验证

浏览器访问地址应由可信 Host 在本机或局域网中提供。上线前请验证身份、访问授权、断开重连、过期会话、网络隔离和日志脱敏。当前 v0.1 是受限公测能力，不应直接暴露到公网。

参见 [架构说明](ARCHITECTURE.zh-CN.md)、[验证记录](VALIDATION-v0.1.zh-CN.md) 和 [安全策略](../SECURITY.md)。
