# 工作台包格式

湾有三类用途不同的工作台数据包。导入器按格式标识和 schema 版本解析，并校验声明文件、大小和摘要。

## 布局包

布局包用于分享工作台结构、标签和经过筛选的可移植状态。它不包含扩展安装制品。接收方需要在自己的 DSH 环境中安装所需扩展，并重新绑定本地 Session。

## 扩展分发包 V4

扩展分发用的 V4 包可以附带依赖清单、权限、发布者身份和在线引用或离线嵌入的制品。包会声明每个文件的路径、大小和 SHA-256 摘要；签名模式还会校验发布者签名。它不包含完整的工作台项目目录或原生 Session。

## 完整工作台包 V6

完整迁移格式使用 workbench-complete V6，导入器也读取 V5。它可以携带工作台根目录、项目目录、原生 Session、附件、上下文、记忆和任务关系，并按声明收集可嵌入的扩展制品。它不等于扩展 V4 包，也不代表其中扩展天然安全或会绕过接收方授权。

## 兼容与迁移

DSH 运行时代际与湾 Core 兼容范围分别校验。布局数据可在受支持的旧数据协议间迁移，但扩展可执行制品必须满足当前 Core 和 DSH 兼容要求。发生冲突时应停止导入并重新生成包，不要手工删除校验字段。

具体 schema 和字段以 `packages/workbench-core/src/foundation/workbench-layout-package.ts`、`workbench-package-v4.ts` 及配套测试为准。
