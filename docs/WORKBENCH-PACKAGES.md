# 工作台包格式

自湾 v0.1.2 起，工作台分享页使用 `.dshbay.zip`（`dshbay-workbench` v1）。导入时校验格式、文件清单、大小和摘要，并检查 DSH 与外部依赖是否兼容。

## 模板包与完整包

- **模板包**：复用工作台结构、布局和项目声明，不含项目文件和对话历史。适合交给别人作为新工作的起点。
- **完整包**：还可携带项目文件、附件和支持恢复的会话。适合迁移工作台；它不是整个用户目录的备份。

导出前检查选中的工作台和扩展依赖，再选择保存目录。导出的文件会保留中文名称，不会覆盖同名文件。导入时先校验，再选择用于恢复工作台的父目录；安装随包扩展前请核对来源和权限。

完整包可能包含私有项目资料、附件和对话历史。请在分享前检查内容，不要分发凭据或未经授权的数据。文件校验通过不代表扩展代码可信。

## 旧格式与扩展分发

当前分享页只接受 `dshbay-workbench` v1，不把旧版布局包、[旧版完整工作台包](COMPLETE-WORKBENCH-V6.zh-CN.md)或对话归档包当作恢复包。扩展分发包有独立的用途和格式，也不能用来恢复整个工作台。更名文件或手工删除校验字段不能转换格式。
