## 本轮根因与修复

1. **标签关闭**：原生草稿保护从未注入 conversation 服务的保留 Session context 取服务，抛异常并阻断关闭。改为从注入根 context 取服务，再定位对应 Session 的输入状态；补齐两个实际入口的注入。浮窗按钮、Delete 和 owner 关闭统一经过保护，失败可见，未发送文字/附件不会无提示丢弃。
2. **来源与落点**：来源栏使用活动标签的项目、对话标记和名称。拖动只命中区域顶栏，在 pointerup 再确认落点；正文释放、取消或 Escape 保持原状。分屏通过菜单完成。
3. **固定/合并损坏布局**：待绑定标签使用浮窗临时 binding 标识，直接固定后不符合 V3 的 binding-N 格式；pending session 标签和已绑定区域合并时也可能形成不一致绑定。已复现工作台因此被解码为 invalid 并切到其他工作台。修复固定前规范化、双向合并绑定继承，并在布局命令及 CAS 前验证 V3。失败保留临时内容，不写非法文档。
4. **控制权交接**：临时标签由 Host 内存暂存，经受信任 Companion 接管和明确收回，传递标签顺序、活动项、绑定、声明 JSON 状态及已固定项。原端在交接时停止写入。缺少返回回执不以旧快照覆盖原端，不把超时当作安全完成；已终止交接也不会因迟到心跳重新放开旧端。

## 明确的边界与未验证项

1. **不是任意内存现场同步**：跨客户端传递内页声明的 JSON 状态、标签和绑定，不保证第三方私有 React 状态、iframe 输入或终端全部现场迁移。同一客户端浮窗→区域的实例和 DOM 保留已实测。
2. **明确收回优先**：使用“收回到 DSH 客户端”完成可靠交接。直接关闭浏览器的 pagehide beacon 是尽力发送，受网络及大小限制；失败时保留原端内容并提示，不承诺同步最后改动。
3. **仅本次运行**：交接快照只在 Host 内存，不进入 Settings、布局包或离线分发包，不跨 Host 重启。各客户端几何偏好独立。
4. **历史另一类白屏未定因**：早期 r8 的自定义内页固定后曾出现 DOM/ARIA 仍在、点击被 HTML 截获的整页空白。它与本轮已定位的非法布局不应混为一谈；不能宣称一并修复。
5. **正式门禁仍阻断**：112 个既有类型错误尚未解决，本包仅作私测。
6. 未覆盖所有真实模型驱动自动联动、多会话、强杀、断连和 CAS 并发组合；未完整验证 Electron 原生浏览器 webview 无损移动。
7. 未接入关闭保护的扩展不具备完整防丢保证；强制结束无法保证异步保护。未自动修复既有损坏记录，也未改动日常 Profile 数据。
