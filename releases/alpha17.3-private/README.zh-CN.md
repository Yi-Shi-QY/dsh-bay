## 本轮修复

- 浮窗显示当前标签的来源项目、绑定对话字母/颜色标记及对话名称。
- 修复浮窗标签和固定到区域后的标签无法关闭；未发送草稿仍经过关闭保护。
- 拖动浮窗标签时，只有区域顶栏接受加入；正文不接收，分屏通过“放入区域”菜单操作。
- 修复待绑定内页固定、合并时写出非法绑定标识或不一致绑定，导致工作台被判无效的问题。
- 临时标签随控制权交接：桌面打开浏览器时带过去，通过“收回到 DSH 客户端”带回来。浏览器中新增、关闭和固定的结果一并带回；不是两端同时编辑或持续双向同步。

## 安装和实测

将 .tgz 作为 **DSH 插件包**安装或更新，不要放入工作台布局导入入口。安装后完整退出并重新启动 DSH，清除旧版本残留的原生侧栏状态。此次验收仅使用隔离 Profile，没有修改日常 Profile。

建议先测试浮窗内关闭、固定后关闭、向区域顶栏拖入、区域双向合并，再测试浏览器新增/关闭/固定标签并收回。跨客户端传递标签、绑定和内页声明的 JSON 状态；任意第三方私有 React 状态、iframe 输入和终端完整现场不保证都能迁移。

请用“收回到 DSH 客户端”完成可靠交接；直接关浏览器依靠尽力发送的退出通知，网络或包体限制可能使其失败，此时原端保留原有内容并提示。临时标签不跨 DSH 重启恢复，重启仅恢复几何偏好；需要持久保存的内容先固定到正式区域。
