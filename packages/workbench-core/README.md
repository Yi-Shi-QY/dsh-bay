# dsh-bay

`dsh-bay` is the Core plugin package for DSH Bay / 湾. Bay turns DSH plugins, Skills, Agents and workbench layouts into assets that can be used, validated, improved and shared. This package provides the Workbench runtime, Creator workflow, portable package handling and DSH integration points.

- Version: `0.1.2`
- DSH compatibility: `>=0.2.2-rc.3 <0.2.3`
- Package type: DSH plugin, not a standalone desktop application

Install `dsh-bay@0.1.2` using DSH's native Plugin Manager. Bay follows the language selected under **Settings → General → Language** in DSH, so the same package supports Chinese and English. For setup and building from source, see the [English README](https://github.com/Yi-Shi-QY/dsh-bay/blob/main/README.en.md), [Chinese user guide](https://github.com/Yi-Shi-QY/dsh-bay/blob/main/docs/USER-GUIDE.zh-CN.md), and [v0.1.2 release notes](https://github.com/Yi-Shi-QY/dsh-bay/blob/main/docs/RELEASE-NOTES-v0.1.2.zh-CN.md).

Review the DSH permissions and extension provenance before installation. Use this plugin only in a DSH environment matching the declared compatibility range.
